# IlliniGuide - UIUC Knowledge Base

A conversational AI guide for UIUC students.

## Project Structure
Detailed file organization rules can be found in [FILE_RULES.md](./FILE_RULES.md).

- **`docs/`**: Setup guides and documentation.
- **`tests/`**: Test scripts.
- **`scripts/`**: Utility scripts.
- **`components/`**: React components.
- **`services/`**: API services.

## Setup
See [docs/CHATFLOW_SETUP.md](docs/CHATFLOW_SETUP.md) for detailed setup instructions.

## Development
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
